# Stock Portfolio Data Analysis

An end-to-end analysis of a Vietnamese stock portfolio using Python, from
macro and sector analysis to stock selection, technical analysis, and
portfolio performance evaluation.

## Project Overview

This project screens a universe of **1,607 stocks listed on HOSE, HNX and
UPCoM**, applies a **value investing** approach to select **3 representative
sectors (1 stock per sector)**, then analyzes each stock with technical
indicators and financial ratios. The final goal is to assess the investment
efficiency of the resulting portfolio.

## Workflow

1. **Market Analysis**
   - Macroeconomic analysis
   - Sector analysis
2. **Investment Strategy**
   - Building a stock selection framework based on value investing
3. **Company Analysis**
   - Company overview
   - Financial statement and financial ratio analysis
4. **Technical & Portfolio Analysis**
   - Price movement and trading volume analysis, Bollinger Bands
   - Efficient Frontier analysis
   - Monte Carlo Simulation
   - Capital Asset Pricing Model (CAPM)
   - 5-year price trend chart (Portfolio Trend)
5. **Conclusion**
   - Evaluation of the portfolio's investment performance based on the
     analyses above
